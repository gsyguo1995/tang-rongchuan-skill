# 经方补正与汇通论证（伤寒/金匮补正增补）

> v1.1 增量：据新入库 modules/06、07（《伤寒论浅注补正》《金匮要略浅注补正》）补充。此二书是唐容川"以西医注仲景"的代表作——汇通论证的核心文本。

## 一、补正两书的定位

- 《伤寒论浅注补正》（7卷，1894 刊行）：推崇陈修园《伤寒论浅注》但认为"此書注解，尚有缺誤"，于陈书基础上补缺正误。前六卷六经证治，每经篇首补总论一篇；卷七为自补论文（识方药离合论/古方加减论/古今方剂大小论/服药法论/劝读十则/医病顺其自然说）
- 《金匮要略浅注补正》（9卷，1893 辑成）：同一方法论用于《金匮》，"合中西《內經》、仲景之書而一以貫之"
- **汇通标志语料**：伤寒补正"西醫"55 次、"連網"40 次、"三焦"178 次、"氣化"54 次——三焦论在此二书最集中

## 二、三焦论的经方展开（伤寒补正核心）

唐氏"腎系連網即三焦"之说在伤寒条文注解中系统展开：

- 三焦为水火游行之路：注五苓散、小柴胡汤诸条反复以"三焦氣化"解水液代谢——"上焦得通，津液得下"
- 連網（西式解剖之中焦膜系）与三焦对译：凡条文涉"腹中痛""心下痞"处，多以膜油烟蒸郁热作解
- 与西医印证点：腸胃發赤、膜油發腫的剖视所见（痢症三字诀亦引）→ 证明"肝火從肝膜入膏油"的中医病机

## 三、卷七论文要点（方法论自述）

| 论 | 要旨 |
|----|------|
| 识方药离合论 | 方与药可合可离——知药性而后知方义，知方义而后能加减 |
| 古方加减论 | 仲景加减皆有法度，不可妄改 |
| 古今方剂大小论 | 汉古今量之辨（与医学见能互参）——古方一剂多分三服，故单次量不峻 |
| 服药法论 | 服法即治法的一部分（顿服/分服/再服的机理） |
| 劝读十则 | 读仲景书的态度论 |
| 医病顺其自然说 | 治病顺气机自然之势，不逆夺 |

## 四、金匮补正的特色病证（新增覆盖域）

- 痰飲咳嗽（45 处）、水氣病（77 处）、婦人篇（87 处）——唐氏以气血水火重新统释金匮杂病
- 血证相关：卷十六"驚悸吐衄下血胸滿瘀血病"——与《血证论》互为表里，金匮原文+血证理论的对读文本
